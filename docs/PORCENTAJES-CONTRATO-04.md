# Calculation profiles

Calculation behavior depends on the selected profile and its precision settings. Shared resources, line order, percentage prefixes, indirect valuation and price locks have distinct roles. A matching grand total does not establish equivalence for every component.

This note follows the current product scope. For the maintained English guide, see [Calculation profiles](CALCULATIONS.md). Use the documentation supplied with an older release when reviewing that build; capabilities and validation may differ.
