# Desktop packages and platform checks

Build each desktop package on its native platform and retain its required layout. Windows uses a self-contained executable; other platforms retain their application bundle or libraries. Source archives are not installers, and a startup check is narrower than full workflow validation.

This note follows the current product scope. For the maintained English guide, see [Desktop packages and platform checks](BUILDING.md). Use the documentation supplied with an older release when reviewing that build; capabilities and validation may differ.
