# BC3 exchange support

BC3 import and export cover a supported subset of FIEBDC-3/2002. Source records and exported edits are different things. Encoding, formulas, percentage rules, aliases and precision can affect compatibility. JSON is the native format for retaining the complete editable project.

This note follows the current product scope. For the maintained English guide, see [BC3 exchange support](COMPATIBILITY.md). Use the documentation supplied with an older release when reviewing that build; capabilities and validation may differ.
