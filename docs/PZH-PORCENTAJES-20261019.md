# PZH import and native copies

PZH support covers examined compact layouts. The importer distinguishes native editable data, source-only information, excluded modules and pending conversions. The source snapshot is preserved, but preservation is not complete semantic conversion. Non-financial control records do not create monetary balances.

This note follows the current product scope. For the maintained English guide, see [PZH import and native copies](COMPATIBILITY.md). Use the documentation supplied with an older release when reviewing that build; capabilities and validation may differ.
