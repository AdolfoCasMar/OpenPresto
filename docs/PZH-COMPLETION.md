## Local evidence for a76

The local scan examined 44 unique PZH files. All imported with native conversion
enabled and recovered the exact original bytes. Across these files, table counts
were: 3: 497; 9: 9,021; 12: 6; 16: 60; 20: 2; 21: 7; 22: 23; 23: 3,801.
Counts are physical records, not verified business meanings or completed modules.

Six files contained indexed entity documentation. One document in each was copied
and its decompressed original bytes compared exactly with native recovery. This
is selected-record evidence, not a check of all 3,801 documents or their layout.

Paid flags and due dates do not establish historical payment dates. Opening
balances cannot reconstruct an absent bank ledger. Additional versions remain
unverified because no representative later-version files are available locally.

The detailed local scan includes private file identities and is intentionally
excluded from public packages. No original third-party files are distributed.

The a77 local development block adds the [auxiliary native module contracts](PZH-AUXILIARY-MODULES.md). These changes remain local pending completion of the agreed scope.
