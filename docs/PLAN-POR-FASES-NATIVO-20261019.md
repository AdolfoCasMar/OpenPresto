# Planning and project monitoring

Dated tasks and fixed-phase quantities are separate planning models. Supported dependencies and calendars are validated. Imported phase approval is reviewed explicitly. Earned-value reporting needs an accepted baseline, progress and actual costs; missing inputs are not inferred from certification or payment data.

This note follows the current product scope. For the maintained English guide, see [Planning and project monitoring](USER-GUIDE.md). Use the documentation supplied with an older release when reviewing that build; capabilities and validation may differ.
