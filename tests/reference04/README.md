# Synthetic regression fixtures

These small BC3 files are original test data. They cover simple breakdowns, shared resources, dimensions, rounding and factors with text. The built-in expected values describe the tested OpenPresto profile; they are not fabricated observations of another application.

Run `python -m unittest discover -s tests -p test_reference04.py -v` from the repository root. External comparison is skipped unless `OPENPRESTO_REFERENCE04` points to an observation JSON file. That optional file must identify the input hashes, calculation profile, expected values and available supporting records. Structural checks do not establish the authenticity of an observation.

Keep input bytes, encoding and line endings stable. Record actual visible results and rejects, retain the original input identity and distinguish measured values from assumptions. Do not replace absent observations with values generated by OpenPresto itself. Share only test material you are entitled to disclose.

Original Spanish labels in fixtures are part of the test data and are retained deliberately.
